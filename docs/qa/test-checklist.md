# Tester's checklist (one page)

*French version: [test-checklist.fr.md](test-checklist.fr.md).* Details: [protocol](test-protocol.md).

**Before** (10 min)
- [ ] I checked the checksums (`SHA256SUMS`) and opened the build with the [instructions](test-build-instructions.md).
- [ ] I noted my machine (system, chip or processor, graphics card, memory).
- [ ] First launch finished (shaders), version read on the title screen: ______

**During** (1 hour)
- [ ] 0-5 min: free walk, controls, one key remapped.
- [ ] A find your way (map, street name, GPS): pass / fail / blocked
- [ ] B rob the shop: pass / fail / blocked
- [ ] C steal a car to order: pass / fail / blocked
- [ ] D lose the police: pass / fail / blocked
- [ ] E save, quit, relaunch, Continue: pass / fail / blocked
- [ ] F night and rain: pass / fail / blocked
- [ ] G cross the quarter by car then on foot: pass / fail / blocked
- [ ] Free play up to 50 min, by day, night and rain.

**After** (10 min)
- [ ] F9 pressed before quitting (and once per serious problem).
- [ ] Quit through the menu.
- [ ] [Feedback form](feedback-form.md) filled; one [bug](bug-template.md) per problem.
- [ ] `Logs`, `Crashes` and `Exports` folders zipped and sent to Nico.

**Blocker?** Crash, freeze over 5 s, impossible scenario, lost save, falling under the world: tell Nico the same day.
