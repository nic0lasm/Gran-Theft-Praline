# Liste de contrôle du testeur (une page)

*Version anglaise : [test-checklist.md](test-checklist.md).* Détails : [protocole](test-protocol.fr.md).

**Avant** (10 min)
- [ ] J'ai vérifié les sommes de contrôle (`SHA256SUMS`) et ouvert la build avec les [instructions](test-build-instructions.fr.md).
- [ ] J'ai noté ma machine (système, puce ou processeur, carte graphique, mémoire).
- [ ] Premier lancement terminé (shaders), version lue à l'écran titre : ______

**Pendant** (1 heure)
- [ ] 0-5 min : marche libre, commandes, une touche remappée.
- [ ] A trouver son chemin (carte, nom de rue, GPS) : réussi / échoué / bloqué
- [ ] B braquer la boutique : réussi / échoué / bloqué
- [ ] C voler une voiture sur commande : réussi / échoué / bloqué
- [ ] D semer la police : réussi / échoué / bloqué
- [ ] E sauvegarder, quitter, relancer, Continuer : réussi / échoué / bloqué
- [ ] F nuit et pluie : réussi / échoué / bloqué
- [ ] G traversée du quartier en voiture puis à pied : réussi / échoué / bloqué
- [ ] Jeu libre jusqu'à 50 min, de jour, de nuit, sous la pluie.

**Après** (10 min)
- [ ] F9 pressé avant de quitter (un export par problème grave aussi).
- [ ] Quitté par le menu.
- [ ] [Formulaire](feedback-form.fr.md) rempli ; un [bogue](bug-template.fr.md) par problème.
- [ ] Dossiers `Logs`, `Crashes` et `Exports` compressés et envoyés à Nico.

**Bloquant ?** Plantage, gel de plus de 5 s, scénario impossible, sauvegarde perdue, chute sous le monde : le dire à Nico le jour même.
