# Modèle de bogue

*Version anglaise : [bug-template.md](bug-template.md).* Un bogue par rapport.

```
Titre : <ce qui se passe>, <où>
Gravité : bloquant (plantage, gel > 5 s, impossible de continuer) / majeur / mineur / cosmétique
Version de la build et nom de l'archive :
Système / puce ou processeur / carte graphique / mémoire :
Profil graphique si vous l'avez changé :
Où (rue, carrefour, en voiture ou à pied, heure du jour, météo) :
Étapes pour reproduire :
 1.
 2.
Attendu :
Constaté :
Fréquence : toujours / souvent / une fois      Revu après redémarrage ? oui / non
Pièces jointes : capture ou vidéo, export (F9) fait juste après, Saved/Logs, Saved/Crashes (compressés)
```

Pour les mainteneurs : un bloquant est traité le jour même ; étiquettes
`bug`, la version, et `mac` ou `windows`.
