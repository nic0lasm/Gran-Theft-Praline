*French version: [bug-template.fr.md](bug-template.fr.md).* One bug per report.

```
Title: <what happens>, <where>
Severity: blocker (crash, freeze > 5 s, cannot continue) / major / minor / cosmetic
Build version and archive name:
System / chip or CPU / GPU / memory:
Graphics profile if you changed it:
Where (street, cross street, in car or on foot, time of day, weather):
Steps to reproduce:
 1.
 2.
Expected:
Actual:
Happens: always / often / once      Seen again after restart? yes / no
Attachments: screenshot or video, export (F9) made right after, Saved/Logs, Saved/Crashes (zipped)
```

For the maintainers: a blocker is triaged the same day; label it with `bug`,
the version, and `mac` or `windows`.
