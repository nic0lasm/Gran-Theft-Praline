# Lyon geodata / Données géographiques de Lyon

- `raw/` — untouched downloads (IGN LiDAR HD, RGE ALTI, BD TOPO, data.grandlyon.com, OpenStreetMap). Large files go through Git LFS or stay out of Git.
- `processed/` — cleaned, cropped and converted data ready for Blender / Unreal.

Conversion scripts live in `tools/geo-pipeline/`. Log every dataset in `assets/SOURCES.md` with its licence (Etalab Open Licence, ODbL).
